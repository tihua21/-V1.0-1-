核对 SQL：

```sql
SELECT booking_no, room_id, booking_date, start_time, end_time, status
  FROM booking
 WHERE booking_date BETWEEN '2027-01-04' AND '2027-01-12'
 ORDER BY booking_date, start_time;

SELECT booking_id, action, from_status, to_status, reason
  FROM booking_audit_log
 WHERE booking_id IN (
     SELECT id FROM booking
      WHERE booking_date BETWEEN '2027-01-04' AND '2027-01-12'
 )
 ORDER BY id;
```

第 9 组取消操作在 `booking_audit_log` 中记为 `action=4, from_status=1, to_status=3`；提交成功的新预约记为 `action=1, from_status=NULL, to_status=1`。

## 四、结论

冲突判定按半开区间 `[start, end)` 实现：`new.start < old.end AND new.end > old.start` 才判冲突。两个「首尾相接」场景均正确放行，未出现把 `end == start` 误判为冲突的情况；同日不同会议室、取消后重订也均按预期放行。
