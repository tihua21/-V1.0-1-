# 初步问题清单

## 一、面向普通用户（学生/教师/行政人员）

-你通常在什么情况下需要预约会议室？预约的频率如何？
-目前你是通过什么渠道或方式预约会议室的？流程大概需要几步？
-预约过程中，你遇到过哪些困难或麻烦？
-预约时你最关心会议室的哪些信息？（如位置、容量、设备、空闲时段等）
-如果系统可以自动检测并提醒时间冲突，你是否觉得有用？
-你希望新系统具备哪些功能来提升预约体验？
-如果临时取消或变更会议，你希望系统如何支持？

## 二、面向管理员（会议室管理人员/行政秘书）

-目前你是如何管理会议室信息和预约记录的？主要依靠什么工具？
-管理工作中，最耗时、最让你头疼的环节是什么？
-遇到预约冲突或违规使用会议室的情况，你通常如何处理？
-你是否需要统计会议室使用率等数据？主要用于什么目的？
-你期望管理员在系统中拥有哪些权限？
-你最希望新系统帮你解决什么具体问题？

## 三、面向系统维护者（IT人员/技术负责人）

-系统预计部署在什么环境？（校内服务器、云服务器等）
-对用户数据安全和系统稳定性有什么具体要求？
-对系统的可维护性、日志记录等方面有何期望？
