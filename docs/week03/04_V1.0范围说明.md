# 智能会议室管理系统 V1.0 范围说明

**负责人：李玉玺**

> 本文档明确"智能会议室管理系统 V1.0——基础预约与管理平台"本学期必须实现的功能、暂不实现的内容，以及范围边界表。
> 决策依据见 [05_方案决策记录.md](./05_方案决策记录.md)，最终选择方案B（固定时段预约 + 管理员审核）。

---

## 一、本学期必须实现

依据任务书规定的最低运行闭环，本学期必须实现以下功能：

1. 用户登录和角色区分
2. 会议室信息管理
3. 会议室查询
4. 预约申请
5. 时间冲突检测
6. 我的预约查看、修改和取消
7. 管理员管理用户
8. 管理员管理会议室
9. 管理员查看和处理预约
10. 数据库设计
11. 基本测试
12. 系统能够启动和演示

---

## 二、本学期暂不实现

可根据小组能力确定，但建议包括：

1. 人脸识别
2. 物联网设备控制
3. 3D 会议室场景
4. 智能推荐
5. 重复预约
6. 多级审批
7. 消息推送
8. 与学校统一身份认证系统对接
9. 移动端原生应用

**注意：** 暂不实现的内容不能替代任务书规定的基础闭环。

---

## 三、范围边界表

| 功能或方向 | V1.0 是否实现 | 原因 | 后续扩展方向 |
|---|---|---|---|
| 用户登录和角色区分 | 是 | 最低闭环要求 | 接入学校统一身份认证系统 |
| 会议室信息管理 | 是 | 最低闭环要求 | 增加会议室设备详情管理 |
| 会议室查询 | 是 | 最低闭环要求 | 增加地图查询、智能筛选 |
| 预约申请 | 是 | 核心业务功能 | 支持重复预约、多级审批 |
| 时间冲突检测 | 是 | 核心业务规则 | 增加智能推荐 |
| 我的预约管理 | 是 | 最低闭环要求 | 增加消息推送提醒 |
| 管理员管理用户 | 是 | 最低闭环要求 | 与统一认证系统对接 |
| 管理员管理会议室 | 是 | 最低闭环要求 | 物联网设备联动 |
