## 二、项目简介

本项目面向校园/单位会议室预约场景，开发智能会议室基础预约与管理平台 V1.0。本学期作为研发的第一阶段，要求学生以团队协作方式，综合运用软件工程方法，完成从问题调研、可行性分析、需求定义、技术选型、系统设计到基础原型实现、测试和部署演示的完整过程。

物联网、人脸识别、3D 场景、复杂智能算法、消息推送、门禁联动等扩展功能**不在本阶段实现**。


## 三、V1.0 功能范围

**普通用户**
- 登录
- 查看会议室
- 选择日期和时间
- 提交预约
- 系统自动判断预约时间冲突，返回预约成功或失败结果
- 查看、修改、取消自己的预约

**管理员**
- 登录
- 管理用户
- 管理会议室
- 查看和处理全部预约

**暂不实现**
- 物联网设备接入
- 人脸识别
- 3D 场景
- 复杂智能算法
- 消息推送、门禁联动

## 六、调研对象

详见《调研计划》和《初步问题清单》。

本次调研覆盖以下三类用户：

1. 普通用户（学生/教师/行政人员）——调研重点为预约流程、使用场景、痛点、功能期望；
2. 管理员（会议室管理人员、行政秘书）——调研重点为管理流程、信息维护、异常处理、统计需求；
3. 其他相关方（系统维护人员）——调研重点为部署与运维要求，仅作非功能性需求参考。
